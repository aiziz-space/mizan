# ميزان

تطبيق PWA شخصي لمتابعة نزول الوزن والسعرات. عربي (RTL)، يشتغل بدون نت، وكل البيانات محفوظة في جهازك.

**الرابط:** https://aiziz-space.github.io/mizan/

للتثبيت على الآيفون: افتح الرابط في Safari → زر المشاركة → «إضافة إلى الشاشة الرئيسية».

## الحسابات
- الهدف اليومي = BMR (Mifflin-St Jeor) × معامل النشاط − (كجم/أسبوع × 7700 ÷ 7)، وأقل حد 1500 للرجال و1200 للنساء.
- الباقي = الهدف + سعرات الرياضة × النسبة − الأكل.
- سعرات النشاط = (MET − 1) × الوزن × الساعات. قيم MET مأخوذة من 2024 Adult Compendium of Physical Activities:
  - مشي عادي 3.8 (17190)
  - مشي سريع 4.8 (17200)
  - أوزان 3.5 (02054)
  - كارديو متوسط 5.0 (02048)، وعالي 9.0 (02049)

بدون framework ولا build step: `index.html`، `styles.css`، `app.js`، `sw.js`.
